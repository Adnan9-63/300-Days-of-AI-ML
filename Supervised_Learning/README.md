# 📈 Supervised Learning

This module focuses on predictive modeling using labeled datasets. It covers both **Regression** (predicting continuous values) and **Classification** (predicting categorical values) techniques.

## 📂 Contents

* **Assignment 1: House Price Prediction (`Assignment_1_HousePrice/`)**  
  Predicting real estate prices using regression techniques.
* **Assignment 2: Employee Turnover (`Assignment_2_EmployeeTurnover/`)**  
  A classification model to predict whether an employee will leave the company based on workplace factors.
* **Assignment 3: Iris Dataset (`Assignment_3_Iris/`)**  
  Solving the classic multi-class classification problem.
* **Assignment 4: ShopSmart E-commerce (`Assignment_4_ShopSmart/`)**  
  Predictive analysis and modeling on an e-commerce customer dataset.
* **🏆 Minor Project 1 - CreditWise (`Minor_Project_1_CreditWise/`)**  
  A comprehensive Loan Approval Prediction System using various classification algorithms to assess default risk and automate loan decisions.

*Note: Each project/assignment folder contains its own specific `README.md` with further details on the problem statement and dataset.*

## 🛠️ Tools & Libraries
* Scikit-Learn (sklearn)
* Pandas & NumPy
* Matplotlib & Seaborn
