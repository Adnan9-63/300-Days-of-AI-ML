# 🧠 Deep Learning

This module contains implementations and experiments with Artificial Neural Networks (ANN) and Convolutional Neural Networks (CNN) as part of the 300 Days of AI/ML journey.

## 📂 Contents

* **ANN Classification & Regression (`ANN_Classification.ipynb`, `ANN_Regression.ipynb`):** Building fully connected neural networks to predict categorical and continuous variables.
* **Neuron Implementation (`Neuron.ipynb`):** Exploring the fundamental building block of deep learning algorithms from scratch.
* **CIFAR-10 Image Classification (`CNN_for_CIFAR10.ipynb`):** Using Convolutional Neural Networks to classify images into 10 distinct categories.
* **Cats vs. Dogs (`cats-vs-dogs-binary-image-classification-using-cnn.ipynb`):** A binary image classification CNN model designed to accurately distinguish between pictures of cats and dogs.

## 🛠️ Tools & Libraries
* TensorFlow / Keras
* PyTorch
* NumPy, Pandas, Matplotlib
