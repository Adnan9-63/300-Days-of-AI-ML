## 📂 Repository Structure

The repository is organized by learning modules and domains:

### 1. 🧮 NumPy Practice (`Numpy_practice`)
* Core foundations of array manipulation, numerical computing, and data handling using NumPy.

### 2. 📈 Supervised Learning (`Supervised_Learning`)
Contains various datasets and predictive models:
* **Assignment 1: House Price Prediction** (Regression)
* **Assignment 2: Employee Turnover** (Classification)
* **Assignment 3: Iris Dataset** (Multi-class Classification)
* **Assignment 4: ShopSmart E-commerce** 
* **🏆 Minor Project 1 - CreditWise:** A comprehensive Loan Approval Prediction System.

### 3. 🔍 Unsupervised Learning (`Unsupervised_Learning`)
Exploration of unlabelled data and dimensionality reduction:
* **Algorithms Implemented:** K-Means, DBSCAN, Hierarchical Clustering, PCA, and Isolation Forest.
* **🏆 Minor Project 2 - SmartCart:** Customer Segmentation utilizing clustering techniques to identify purchasing behaviors.

### 4. 🧠 Deep Learning (`Deeplearning`)
Diving into neural networks and computer vision:
* **ANN (Artificial Neural Networks):** Implementations for both Classification and Regression.
* **CNN (Convolutional Neural Networks):** CIFAR-10 Image Classification and Cats vs. Dogs binary classification.

### 5. 🤖 Reinforcement Learning (`Reinforcement_learning`)
Teaching agents to make decisions based on environments:
* **SARSA Algorithm** implementations.
* **🎮 Flappy Bird Agent:** An autonomous agent that learns to play Flappy Bird using Deep Q-Networks (DQN) and Experience Replay.
