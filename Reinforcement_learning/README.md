# 🤖 Reinforcement Learning

This module explores how AI agents can learn to make decisions by interacting with an environment to maximize cumulative rewards.

## 📂 Contents

* **SARSA Algorithm (`SARSA.ipynb`):** Implementation of the State-Action-Reward-State-Action (SARSA) on-policy reinforcement learning algorithm to solve fundamental grid/pathfinding problems.
* **🎮 Flappy Bird Agent (`flappy_bird_agent/`):** A comprehensive project where an AI agent learns to play the game Flappy Bird. It utilizes Deep Q-Networks (DQN) and Experience Replay to achieve superhuman performance. *See the specific `README.md` inside this folder for detailed architecture and hyperparameters.*

## 🛠️ Tools & Libraries
* PyTorch
* OpenAI Gym / Gymnasium
* NumPy
